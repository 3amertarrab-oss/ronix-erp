# حسابات RONIX — تحديث 006

تاريخ الإنجاز: 20 نوفمبر 2026.

- إصلاح فتح واجهة مركز المسوّق الجديدة بدل الرجوع إلى الواجهة القديمة.
- احتساب اكتمال التحصيل من قيمة العقد المحاسبية الحالية، وليس الحقل القديم.
- إتاحة إصدار فاتورة المسوّق عندما يغطي التحصيل المسجل قيمة العقد.
- إظهار عمولات ودفعات المسوّقين في ملف المشروع المطبوع.
- الحفاظ على جميع بيانات وصور ومرفقات الإصدارات السابقة.

# حسابات RONIX — تحديث 004

تاريخ الإنجاز: 20 نوفمبر 2026.

## المطالبات

- شريط واضح لخمس خطوات: البيانات، المشاريع، البنود، العملة، المراجعة.
- بطاقة مالية لكل مشروع تعرض العقد الأصلي والإضافات والخصومات والعقد المعدل.
- عرض المطالبات السابقة والتحصيل والمتاح والقيمة الحالية والمتبقي بعدها.
- إخفاء حقول الصرف لمشاريع الجنيه وإظهارها للعقود الأجنبية فقط.
- أخطاء داخل النموذج تحدد المشروع والحقل ثم تنقل المستخدم إليه.
- شريط حفظ وطباعة ثابت أسفل نافذة المطالبة.
- معاينة مطابقة التحصيل: المتاح، الذي سيُربط، المسدد بعد الربط والمتبقي.
- إضافة المبلغ كتابةً إلى النسخة المطبوعة.

## الحماية

التحديث واجهة وحسابات مشتقة فقط. لا يغير معرفات المطالبات القديمة ولا بنودها
ولا صور المشاريع ومرفقات `ronix-files`. تظل مطابقة التحصيل ربطًا بين السند
والمطالبة ولا تنشئ قبضًا جديدًا.

# حسابات RONIX — تحديث 018

## إخراج المطالبة للعميل

- لكل مشروع صفحة مستقلة تبدأ بصورة كبيرة محفوظة من ملف المشروع.
- يظهر اسم المشروع وكوده وموقعه فوق الصورة بوضوح.
- يعرض الاتفاق الأصلي وصافي أوامر التغيير والقيمة الحالية بعد VO.
- يعرض كل VO مع الاسم والتاريخ ونوع التأثير والقيمة والإجمالي بعده.
- يعرض بنود المطالبة الحالية في جدول منفصل.
- يشرح المطالبات السابقة والدفعات المسجلة والمبلغ المطابق والمتبقي الآن.
- يجمع المستند في خلاصة نهائية واحدة، ويضع علامة واضحة على المسودة.
- تبقى العمولات والمصروفات الداخلية مخفية تمامًا عن نسخة العميل.

لم تُحذف أو تُحوّل أي بيانات أو صور أو مرفقات، والتغيير خاص بطريقة العرض والطباعة.

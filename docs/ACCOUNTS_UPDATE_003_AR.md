# حسابات RONIX — تحديث 003

تاريخ الإنجاز: 20 نوفمبر 2026.

## ما أضيف

- قسم مستقل للمسوّقين.
- عمولة ثابتة أو نسبة من عقد المشروع.
- إدراج العمولة ضمن تكلفة المشروع.
- منع إصدار فاتورة المسوّق قبل اكتمال تحصيل عقد المشروع.
- فاتورة قابلة للطباعة والحفظ PDF.
- تسجيل دفعات المسوّق وحساب المسدد والمتبقي.
- كشف حساب مستقل لكل مسوّق.

## حماية البيانات

التحديث يضيف الجداول `marketerAssignments` و`marketerInvoices` و`marketerPayments`
إلى حمولة Supabase الحالية. لا يغيّر معرفات المشاريع أو المطالبات، ولا يمس مراجع
الصور والمرفقات المخزنة في `ronix-files`. النسخ القديمة تُفتح والجداول الجديدة تبدأ
فارغة، وتستمر المزامنة بأسلوب المراجعة والمقارنة الحالي.

## النشر

العامل المستهدف هو `fancy-pond-cb20` فقط. أمر النشر:

```sh
npx wrangler deploy --config wrangler.jsonc
```

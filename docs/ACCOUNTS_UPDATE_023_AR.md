# حسابات RONIX — تحديث 023

- اعتماد إخراج المطالبة بنفس اللغة البصرية لكشف حساب العميل المرجعي.
- فصل قيمة التعاقد الأساسية عن أوامر التغيير VO.
- عرض كل VO في صف مستقل مع الطريقة والنسبة وأساس الاحتساب والقيمة الناتجة.
- عرض إجمالي ما بعد VO وقيمة المطالبة والمطلوب في أعمدة مستقلة.
- إضافة جدول واضح للدفعات المطابقة أسفل جدول المشاريع.
- دعم تعدد أوامر التغيير للمشروع دون دمجها أو إخفاء طريقة حسابها.

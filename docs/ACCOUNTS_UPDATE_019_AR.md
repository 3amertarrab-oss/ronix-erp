# حسابات RONIX — تحديث 019

- سطر بصري واحد لكل مشروع داخل المطالبة.
- صورة كبيرة على جانب السطر مع اسم المشروع والكود والموقع.
- الاتفاق الأصلي وVO والاتفاق المعدل والمطالبة والمسدد والمطلوب تظهر مرة واحدة.
- تفاصيل VO وبنود المطالبة قابلة للفتح عند الحاجة.
- عند وجود عدة مشاريع ترتب الأسطر تحت بعضها وتظهر خلاصة واحدة في النهاية.
- تخفي الطباعة التفاصيل الثانوية والأزرار لتخرج نسخة نظيفة للعميل.
- لم تتغير البيانات أو الصور أو المرفقات، ولم تُحذف أي حركة مالية.

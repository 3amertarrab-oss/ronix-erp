# حسابات RONIX — تحديث 011

تاريخ الإنجاز: 20 نوفمبر 2026

## تصنيف عمولات المسوّقين

- العمولة المتفق عليها تُعرض كاتفاق ولا تصبح دينًا بمجرد التكليف.
- قبل الفاتورة تظهر ضمن «غير المفوتر»، ويكون المستحق والمتبقي المستحق صفرًا.
- الفاتورة المرسلة للمدير تظهر ضمن «بانتظار الاعتماد»، ولا يسمح بدفعها.
- بعد الاعتماد تنتقل قيمة الفاتورة إلى «المستحق للدفع» ويظهر زر «دفعة +».
- الدفعات الجزئية تُظهر المدفوع والمتبقي المستحق والحالة «مسدد جزئيًا».
- بعد اكتمال الدفع تصبح الحالة «مسدد بالكامل» ويختفي زر الدفعة.

## حماية السجل

لم يتم حذف أو تعديل الفواتير أو الدفعات أو الصور السابقة؛ التحديث يعيد تصنيف عرض الأرقام حسب مرحلتها المالية فقط.

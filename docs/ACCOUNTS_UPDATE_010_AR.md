# حسابات RONIX — تحديث 010

تاريخ الإنجاز: 20 نوفمبر 2026

## واجهة المسوّق داخل المشروع

- إزالة القسم القديم «المسوّقون وعمولات المشروع» لمنع التكرار.
- إنشاء جدول «تكليفات المسوّقين» بنفس أسلوب جدول تكليفات المصممين.
- عرض المسوّق، التكليف، العمولة، المدفوع، المتبقي، الحالة والإجراءات في صف واحد.
- الضغط على اسم المسوّق يفتح مركز حسابه وكل مشاريعه وفواتيره ودفعاته.
- الإجراءات الديناميكية: تعديل، إصدار فاتورة، دفعة، فتح الفاتورة، وحذف التكليف قبل الفوترة.

## الحماية المالية

- حذف التكليف قبل الفوترة يتطلب سببًا ويحفظه في سجل المراجعة.
- بعد إصدار فاتورة لا يظهر حذف مباشر؛ يجب عكس الفاتورة محاسبيًا أولًا حتى لا يختفي تاريخ مالي أو مرفق.
- الصور والفواتير والدفعات القديمة محفوظة دون تغيير.

# حسابات RONIX — تحديث 020

- إظهار إجمالي دفعات العميل المسجلة لكل مشروع داخل المطالبة.
- قائمة بالدفعات تتضمن التاريخ والسند وطريقة الدفع والقيمة.
- فصل «إجمالي دفعات المشروع» عن «المطابق مع المطالبة».
- المطلوب في المطالبة يُخصم منه المبلغ المطابق فقط لمنع تكرار استخدام الدفعة.
- لم يتم تعديل أو حذف أي سند أو مطابقة أو صورة؛ التغيير خاص بطريقة العرض.

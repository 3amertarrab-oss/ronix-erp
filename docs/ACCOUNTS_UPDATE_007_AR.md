# حسابات RONIX — تحديث 007

تاريخ الإنجاز: 20 نوفمبر 2026.

## المرونة

- العمولة مبلغ ثابت، أو نسبة من العقد، أو نسبة من التحصيل.
- الاستحقاق بعد التحصيل الكامل، أو العربون، أو مع كل تحصيل، أو بتاريخ، أو يدويًا.
- اعتماد المدير إلزامي أو اختياري لكل اتفاق.

## المستندات والرقابة

- فاتورة المسوّق لها رقم خارجي وصورة أو PDF وحالة اعتماد.
- منع تكرار رقم الفاتورة للمسوّق نفسه.
- منع الدفع قبل الاعتماد أو بأكثر من المتبقي.
- كل دفعة لها سند مستقل ومرجع وصورة تحويل.
- كشف حساب PDF لكل مسوّق بالحركات والرصيد المتتابع.

كل الحقول والجداول إضافية، وتظل بيانات وصور ومرفقات الإصدارات السابقة محفوظة.

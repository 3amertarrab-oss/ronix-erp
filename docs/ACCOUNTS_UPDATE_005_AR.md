# حسابات RONIX — تحديث 005

تاريخ الإنجاز: 20 نوفمبر 2026.

## مركز المسوّق

- مركز حساب مستقل لكل مسوّق مثل المصمم.
- عرض المشاريع والعمولات والفواتير والدفعات والرصيد المتبقي.
- فتح جميع فواتير المسوّق من مكان واحد وطباعتها.
- إرفاق صورة أو PDF لكل فاتورة مسوّق وعرضها أو تنزيلها لاحقًا.
- ظهور ملخص المسوّقين في الداشبورد وفي صفحة المشروع.
- ظهور اسم المسوّق وعمولته وفاتورته ومدفوعاته في ملف المشروع المطبوع.

## حماية البيانات والصور

التحديث إضافي ولا يغيّر معرفات أو قيم سجلات المسوّقين السابقة. مرفقات الفواتير
تستخدم مخزن المرفقات المحمي نفسه، ولذلك تدخل في النسخة الاحتياطية والمزامنة السحابية
وفحص سلامة الوسائط. لا تُحذف مشاريع أو مطالبات أو صور أو مرفقات قديمة.

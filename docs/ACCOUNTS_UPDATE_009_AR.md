# حسابات RONIX — تحديث 009

تاريخ الإنجاز: 20 نوفمبر 2026

## المرونة الجديدة للمسوّقين

- زر «+ مشروع / عمولة» داخل صف كل مسوّق.
- اختيار المشروع من بطاقات مصورة قابلة للبحث، وتعرض المشاريع النشطة فقط.
- تعديل طريقة العمولة وقيمتها وموعد استحقاقها واعتمادها وملاحظاتها قبل إصدار الفاتورة.
- بعد إصدار الفاتورة تُقفل القيمة المالية لحماية السجل السابق، مع بقاء تعديل الاستحقاق والملاحظات متاحًا.
- زر «تعديل التكليف» داخل مركز حساب المسوّق.
- إصدار فاتورة المسوّق ثم تسجيل دفعة وسند دفع ومرفقه من مركز الحساب نفسه.

## حماية البيانات

التحديث إضافي ولا يحذف المشاريع أو المسوّقين أو الفواتير أو الدفعات أو الصور القديمة. كل تعديل مالي يُحفظ في سجل المراجعة.

# حسابات RONIX — تحديث 008

تاريخ الإنجاز: 20 نوفمبر 2026

## ما تم تنفيذه

1. إزالة تكرار أقسام المسوّقين داخل المشروع، وإبقاء قسم موحّد واحد.
2. إضافة مؤشرات المسوّقين إلى نظرة المشروع: العدد، إجمالي العمولات، المدفوع، المتبقي، وما ينتظر الاعتماد.
3. تحويل التايم لاين إلى سجل تفاعلي: فتح كل حركة، عرض تفاصيلها، تنفيذ الإجراء المناسب، إضافة وحذف الملاحظات بسبب مسجل، واستكمال التاريخ الناقص.
4. إنشاء دليل مستقل للمسوّقين مثل المصممين، ثم اختيار المسوّق المسجل عند ربطه بالمشروع. الأرشفة لا تمحو حساباته أو فواتيره أو دفعاته.
5. استبدال قائمة اختيار المشروع في «إضافة حركة» ببطاقات مصورة قابلة للبحث، مع فصل المشاريع النشطة عن المقفولة.

## حماية البيانات والصور

- التغييرات إضافية ولا تستبدل المشاريع أو المطالبات أو المقبوضات القديمة.
- الصور والمرفقات تستمر في مخزنها المحمي الحالي ولا تُحوّل إلى بيانات عامة.
- أرشفة المسوّق تحفظ كل تاريخه المالي.
- حذف ملاحظات التايم لاين يتطلب سببًا ويُسجل في سجل المراجعة.
- المشروع المقفول يظهر للعرض فقط ولا يفتح نموذج إضافة حركة جديدة.

# حسابات RONIX — تحديث 012

تاريخ الإنجاز: 20 نوفمبر 2026

## لوحة الإدارة الجديدة

- ملخص تنفيذي من خمسة مؤشرات رئيسية دون تكرار الأرقام.
- تنبيهات تظهر فقط عند وجود فاتورة أو مطالبة أو عمولة تحتاج إجراءً.
- الضغط على البطاقة ينقل إلى التفاصيل المرتبطة بها.
- تبويبات انسيابية: العملاء والتحصيل، المستحقون، المشاريع، السيولة والربح.
- زر «+ إضافة» يفتح إجراءات واضحة للحركة على مشروع أو دفع مستحق أو كشف عميل.
- التفاصيل المالية القديمة محفوظة داخل قسم قابل للفتح بدل عرضها كلها دفعة واحدة.
- حدود بصرية خفيفة، وألوان لها معنى: أخضر للمحصل، أحمر للمستحق الفعلي، وذهبي للقرار.
- تخطيط متجاوب للهاتف يحول البطاقات والأزرار إلى أعمدة مناسبة للمس.

## حماية البيانات

إعادة التصميم خاصة بالعرض والتنقل، ولا تحذف أو تعدل المشاريع أو المطالبات أو الفواتير أو الدفعات أو الصور والمرفقات.
